# Design Resources

When working on frontend, UI, UX, maps, or visual design:

- Use the local `canvas-design` skill from `.claude/skills`.
- Use the installed `frontend-design` plugin.
- Use the installed `ui-ux-pro-max` plugin.

These resources may come from either local skills or installed plugins. Do not assume every resource exists under `.claude/skills`.

- Prefer modern, accessible, responsive interfaces.
- Follow the design system before introducing new UI patterns.
- Keep components visually consistent across the project.
